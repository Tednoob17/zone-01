What is this?
This is a wargame site providing various web-based challenges. It was originally created because we felt that there was a lack of good and non-trivial web challenges available, and also because we wanted to share with others interesting problems/issues that we have encountered.
How to play?
The goal for each challenge is to find the flag, a string of the form WEBSEC{…} by exploiting one (or more) web-related vulnerability. Every challenge is solvable. Each levels runs under a specific user in an empty chroot, and comes with a phpinfo.php (it won't help you, but some people asked for it).

You can create an account if you wish to compete with others, but it's not required.
What are the bonus levels?
The bonus levels won't give you any points, and are usually exotic ones about convoluted vulnerabilities, that aren't fitting very well with the rest of the game, but that are still worth spending some time on them if you like to bang your head against walls.
Rules
  1. All kind of DoS are (lame and) forbidden. We're creating this wargame on our free time, for fun, so please don't ruin it, for us, and the other players ♥
  2. If you find an unintended bug or issue, please report it, you'll be credited.
  3. Please refrain from posting detailed public writeups.
  4. Don't be a dick.
Accounts
If you lost your password, you're likely screwed: we don't ask (nor want) email addresses, so we can't send you reset tokens,
and except if you manage to prove us that you're the entity behind a nick, we won't delete it (although we might delete inactive or unused accounts), nor reset its password.

We're keeping as much logs as your usual VPN provider.
Contact and help
Everyone is likely hanging on the irc channel, #websec. Even if you don't need help, you're welcome to drop by and idle socialize.

Also, despite the fact that we do our very best to produce a fun, challenging and interesting wargame, we can't think about everything: if you think you found a way to improve something, don't be afraid to tell us. Moreover, if you have an interesting idea that you want to transform into a level, we're interested too.
Resources
This is a short list of content that we like, and that might help you to get a better understanding of the state of web security.

  • Books
    • The Tangled Web: A Guide to Securing Modern Web Applications, by Michal (lcamtuf) Zalewski
    • The Web Application Hackers Handbook, by Dafydd Stuttard (the creator of Burp Suite) and Marcus Pinto

  • Online reading
    • The database of websec.ca about sql injections
    • Postcards from the post-XSS world , by Michal Zalewski
    • The OAuth Security Cheatsheet
    • Pentestmonkey's cheat sheet about sql injection
    • Paragon initiative's blog about common pitfalls in PHP
    • The MDN section about web security
    • PHP the right way is a nice initiative if you don't plan to transform your web application into a wargame.
