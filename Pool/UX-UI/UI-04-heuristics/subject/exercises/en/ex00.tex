\textbf{Context:}

Welcome to this very last quest!

The point is to take on the role of a UX auditor. You'll be asked to make the audit of a website or an app, and then to write a series of recommendations to improve it.

Let's be critical, creative and impactful!

\textbf{Instructions:}

Run a heuristic audit on one of these 3 different websites or app:

\begin{itemize}
\item https://www.ikea.com/ \url{https://www.ikea.com/}
\item https://www.doctorswithoutborders.org/ \url{https://www.doctorswithoutborders.org/}
\item App WikiArt
\end{itemize}

\textbf{Deliverables:}

\begin{itemize}
\item A completed chart
\item A report including the 5 recommended steps described below
\item Upload the documents on Github, in a zip folder named "ProjectTitle\_Name\_FirstName", with all project deliverables as follows: "Name\_FirstName\_DeliverableName\_Date\_VersionNumber".  For example, the first deliverable can be named as "Doe\_John\_MidFiPrototype\_05242024\_V1".
\item Add a title within all written documents.
\item Pay attention to the global aspect of the deliverables. They must be clear, simple and easy to read. You can get inspiration on canva.com but don't overload your design with too much details!
\end{itemize}

\textbf{Tips:}

\begin{itemize}
\item Recommended steps
\begin{itemize}
\item Define the scope.
\end{itemize}
\end{itemize}
1. Know the business requirements and demographic of the end-users.
2. Decide on which reporting tools and heuristics to use (in this case: this heuristic evaluation checklist \url{https://drive.google.com/file/d/10KbfbNZA1oVS1sXbjjXLPPmdZ6nqVkdc/view}).
3. Evaluate the experience and identify usability issues.
4. Analyze and aggregate the data.
5. Present the results.
