\textbf{Instructions :}

Prepare a protocol for usability testing.

\textbf{Livrable :}

\begin{itemize}
\item A PDF document with a test protocol
\item Déposez le PDF sur Github, nommé ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans le document.
\item Soignez l'aspect global du document. Il doit être clair, simple et lisible. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Tips:} Recommended steps

\begin{itemize}
\item Define the scope of the test
\item Recruit 5 users
\item Identify objectives: What are you proving?
\item Establish metrics:  How are you proving your design is efficient?
\item Describe the steps and the instructions
\item Write an introduction to greet ther user
\item Write a conclusion to thank the user
\end{itemize}
