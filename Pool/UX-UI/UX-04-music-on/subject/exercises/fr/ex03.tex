\textbf{Instructions :}

In the present situation, the websites are not ideal to complete the Jobs-to-be-Done your user has in mind. So let's practice card sorting to rearrange the content of the website!

Organize a card sorting workshop with the content of the website you chose in Ex. 1.

To do so:

\begin{itemize}
\item Define your research goals
\item Prepare the material
\item Find participants
\item Run a card sorting workshop on 5 people
\item Suggest a new taxonomy (content organization)
\end{itemize}

\textbf{Livrables :}

\begin{itemize}
\item A card sorting workshop script with the research goals (PDF document)
\item Des photos de l'atelier en cours
\item A document to show the new content organization (it can be a picture of the board with sticky notes or the digital version).
\item Déposez les documents sur Github, dans un zip nommé « ProjectTitle\_Name\_FirstName », et chaque livrable ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans tous les documents écrits.
\item Soignez l'aspect global des livrables. Ils doivent être clairs, simples et lisibles. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}
