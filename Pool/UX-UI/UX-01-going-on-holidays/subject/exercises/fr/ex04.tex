\textbf{Instructions :}

Pour trouver des solutions créatives à votre énoncé de problème, utilisez l'une de ces techniques en groupes de 5 personnes, deux fois.

Formez des binômes. Lors du premier passage, l'un est le facilitateur et l'autre est le time-keeper et s'occupe de la logistique. Inversez les rôles pour le second passage.

Générez autant d'idées que possible dans un temps défini, puis réduisez-les à 3 idées principales par un processus de vote (en binôme ou en groupe). Prenez des photos !

\textbf{Livrables :}

\begin{itemize}
\item Un document PDF qui comprend le script avec toutes les étapes + la logistique
\item Photos des 2 sessions
\item Un document PDF avec 3 idées issues des 2 ateliers.
\item Déposez les documents sur Github, dans un zip nommé « ProjectTitle\_Name\_FirstName », et chaque livrable ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans tous les documents écrits.
\item Soignez l'aspect global des livrables. Ils doivent être clairs, simples et lisibles. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}
