\textbf{Contexte :}

This first UI quest is a series of exercises to practice colors, moodboards, typography and replicate screens on Figma!

\textbf{Instructions :}

Go to these 7 websites and make the color palettes out of them (3 to 4 main colors).

\textbf{Livrable :}

\begin{itemize}
\item A Figma file including screenshots of the main page, URL and extracted colors next to the screenshots.
\item Déposez le fichier Figma sur Github, nommé ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans le fichier.
\item Soignez l'aspect global du fichier. Il doit être clair, simple et lisible. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Pistes :}

\begin{itemize}
\item You can use Figma to extract the colors you need and export your file to PDF.
\item Use the Color Pipette to extract the colors!
\item You can show the main colors with filled squares or circles next to the screenshots. 
\item Mind the aesthetics of your delivrable! 1 page per site should be good.
\end{itemize}
