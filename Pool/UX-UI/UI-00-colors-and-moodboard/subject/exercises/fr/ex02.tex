\textbf{Instructions :}

Naviguons !

Trouvez 3 produits numériques (sites web ou applications) qui utilisent chaque type de combinaison de palette de couleurs :

\begin{itemize}
\item Monochromatique
\item Analogue
\item Complémentaire
\item Complémentaire scindé
\item Triadique
\item Double complémentaire
\end{itemize}

\textbf{Livrable :}

\begin{itemize}
\item Un fichier Figma comprenant, pour chaque produit numérique (sites ou applications)
\begin{itemize}
\item captures d'écran de la page principale
\item l'URL correspondante
\item les couleurs principales et
\item le type de combinaison de couleurs.
\end{itemize}
\item Déposez le fichier Figma sur Github, nommé ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans le fichier.
\item Soignez l'aspect global du fichier. Il doit être clair, simple et lisible. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Pistes :}

\begin{itemize}
\item Vous pouvez trouver HSB (Teinte, Saturation, Luminosité) ainsi que HSV (Teinte, Saturation, Valeur) selon la source.
\end{itemize}
