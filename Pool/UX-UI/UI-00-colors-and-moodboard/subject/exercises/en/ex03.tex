\textbf{Instructions:}

Create 4 different moodboards based on these 4 briefs and extract a color palette.

\textbf{Briefs:}

\begin{itemize}
\item 1: A physics teacher that wants to make his website catchy for 12 year-olds.
\item 2: A Sri Lankan wedding planner website that wants to breathe sobriety and modernity.
\item 3: An e-commerce platform that sells West African wax and wants to feel more luxurious in its spirit to stand out.
\item 4: An NGO that helps parents of kids with autism, wants to spread joy and hope for a fundraiser.
\end{itemize}

\textbf{Deliverables:}

\begin{itemize}
\item A Figma file per moodboard
\item On each moodboard, several pictures (5 to 12) that are graphically consistent in terms of colors
\item The main colors extracted and shown on the side
\item One color code per color (RGB, Hex or HSB)
\item Upload the documents on Github, in a zip folder named "ProjectTitle\_Name\_FirstName", with all project deliverables as follows: "Name\_FirstName\_DeliverableName\_Date\_VersionNumber".  For example, the first deliverable can be named as "Doe\_John\_MidFiPrototype\_05242024\_V1".
\item Add a title within all written documents.
\item Pay attention to the global aspect of the deliverables. They must be clear, simple and easy to read. You can get inspiration on canva.com but don't overload your design with too much details!
\end{itemize}
