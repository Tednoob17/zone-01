\textbf{Instructions:}

Go to these 7 websites and make the color palettes out of them (3 to 4 main colors).

\textbf{Deliverable:}

\begin{itemize}
\item A Figma file including screenshots of the main page, URL, extracted colors and the matching color codes.
\item Upload the Figma file on Github, labeled as follows: "Name\_FirstName\_DeliverableName\_Date\_VersionNumber". For example, it can be labeled as "Doe\_John\_MidFiPrototype\_05242024\_V1".
\item Add a title within the file.
\item Pay attention to the global aspect of the file. It must be clear, simple and easy to read. You can get inspiration on canva.com but don't overload your design with too much details!
\end{itemize}

\textbf{Tips:}

\begin{itemize}
\item You can use the document from the previous exercise to add the color codes on Figma.
\item Use the Color Pipette to detect the color codes!
\end{itemize}
