\textbf{Contexte :}

Le client de votre entreprise est une chaîne de cinémas appelée Movie 4 all.

Ils veulent lancer une plateforme pour les personnes qui veulent regarder des films mais ne veulent pas passer un temps infini à en choisir un.
Vous remplacez quelqu'un dans l'entreprise qui a déjà travaillé sur la recherche utilisateur, l'énoncé de problème et la liste des fonctionnalités qu'ils prévoient de développer. Votre objectif est de prototyper et de tester ces fonctionnalités.

\textbf{Instructions :}

À partir des 3 fonctionnalités sorties des ateliers d'idéation menés par vos collègues, concevez 3 user flows (1 par fonctionnalité).

Fonctionnalités :

\begin{itemize}
\item 1 : Ajouter un filtre basé sur leur humeur du moment
\item 2 : Proposer une sélection de 3 films à regarder
\item 3 : Demander aux utilisateurs de noter le film après l'avoir regardé pour affiner les recommandations
\end{itemize}

\textbf{Livrables :}

\begin{itemize}
\item 3 parcours utilisateurs sur un board (numérique ou photos d'un board papier)
\item Déposez les documents sur Github, dans un zip nommé « ProjectTitle\_Name\_FirstName », et chaque livrable ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans tous les documents écrits.
\item Soignez l'aspect global des livrables. Ils doivent être clairs, simples et lisibles. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}
