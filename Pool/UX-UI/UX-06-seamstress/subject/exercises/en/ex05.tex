\textbf{Instructions:}

Make a prototype including the chosen solution.

\textbf{Deliverables:}

\begin{itemize}
\item Pictures of a paper prototype (low-fi)
\item An animated wireframe prototype (mid-fi)
\item Key learnings from this phase
\item Vocabulary
\begin{itemize}
\item Low-Fidelity: Paper Prototypes - Example here \url{https://miro.medium.com/max/1400/1*5nUfqqA2gjdAYHagjbHA5w.jpeg}
\item Mid-Fidelity: Wireframes - black and white, only the main elements, on digital prototype tools - Example here \url{https://miro.medium.com/max/1400/1*eGSfaxwYbxUFomYbyO6GWw.png}
\item High-Fidelity: Wireframes with color, styles, graphical details, and micro-interactions - Example here \url{https://miro.medium.com/max/1400/1*Xn0HSKAvhr4TZzC9lN5udw.gif}
\end{itemize}
\item Upload the documents on Github, in a zip folder named "ProjectTitle\_Name\_FirstName", with all project deliverables as follows: "Name\_FirstName\_DeliverableName\_Date\_VersionNumber".  For example, the first deliverable can be named as "Doe\_John\_MidFiPrototype\_05242024\_V1".
\item Add a title within all written documents.
\item Pay attention to the global aspect of the deliverables. They must be clear, simple and easy to read. You can get inspiration on canva.com but don't overload your design with too much details!
\end{itemize}

\textbf{Tips:}

\begin{itemize}
\item Use as many tools as needed, and make sure you do all the process in 4 working days!
\item You may use Card Sorting and User flows
\end{itemize}

\textbf{Criteria:}

\subsubsection*{Criteria}

\begin{itemize}
\item User Flow
\end{itemize}

Make sure for each flow:

\begin{itemize}
\item The user has a specific goal
\item There is a starting point and and ending point - which is the goal of the user
\item There is a series of actions organised in rectangles (actions) or diamond (choice)
\item The actions are linked with arrows
\end{itemize}

\begin{itemize}
\item Card sorting
\end{itemize}

Make sure

\begin{itemize}
\item There is a script including the research goals.
\item The research goals must be close to "rearrange the content"
\item There are pictures of the ongoing workshop
\item There is a new content organization shown in a table with sticky notes (it can be a picture or digital)
\end{itemize}
