\textbf{Instructions :}

Run at least one of the Empathy tools in the design process.

\textbf{Livrables :}

\begin{itemize}
\item A PDF document with the script of the tool context
\item Completed tool (scripts from user interviews, results from a quantitative analysis, etc.)
\item A PDF document with the key learnings from this phase
\item Déposez les documents sur Github, dans un zip nommé « ProjectTitle\_Name\_FirstName », et chaque livrable ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans tous les documents écrits.
\item Soignez l'aspect global des livrables. Ils doivent être clairs, simples et lisibles. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Pistes :}

\begin{itemize}
\item Use as many tools as needed, be make sure you do all the process in 4 working days!
\end{itemize}

\textbf{Critères :}

\begin{itemize}
\item User interviews
\begin{itemize}
\item The script is the interview guide. Make sure there is:
\begin{itemize}
\item the main purpose of the interview
\item 1 to 3 hypotheses
\item a proper introduction that describes the interviewer and the purpose of this interview
\item 3 to 5 main topics
\item a few scan questions (demographics)
\item open-ended questions, max 10
\item a funnel process (>)
\item a conclusion with next steps and a thank you.
\end{itemize}
\item The completed tool is either:
\begin{itemize}
\item 5 to 10 scripts from users
\item or an Affinity Diagram \url{https://www.youtube.com/watch?v=VngWHIE4k9s} with the main elements
\end{itemize}
\end{itemize}
\end{itemize}

\begin{itemize}
\item Analytics
\begin{itemize}
\item The script is the form. Make sure there is:
\begin{itemize}
\item The main purpose of the form
\item 1 to 3 hypotheses
\item A proper introduction that describes the interviewer and the purpose of this interview
\item 3 to 5 main topics
\item A few scan questions (demographics)
\item Closed-ended, unbiased questions, max 10
\item A funnel process (>)
\item A conclusion with next steps and a thank you.
\item A broadcast strategy
\end{itemize}
\item The completed tool is a series of quantitative data from at least 100 answers.
\end{itemize}
\end{itemize}

\begin{itemize}
\item Competitive analysis
\begin{itemize}
\item The script is the strategy. The student explains what they are looking for and how they plan to find it.
\item The completed tool is a report. Make sure there is;
\begin{itemize}
\item There is an introduction
\item There is a competitive landscape \url{https://venngage-wordpress.s3.amazonaws.com/uploads/2019/03/g2crowd-grid.png}
\item With 2 relevant axes
\item 10 organizations appear on the landscape
\item There is a competitive table \url{https://venngage-wordpress.s3.amazonaws.com/uploads/2019/03/product-features-comparison-matrix.png}
\item With 5 to 10 criteria
\item 10 organizations appear on the table
\end{itemize}
\end{itemize}
\end{itemize}
