\makeheaderfiles

\textbf{Instructions :}

Utilisez au moins un des outils Define du processus de design.

\textbf{Livrables :}

\begin{itemize}
\item Un document PDF avec le script du contexte de l'outil
\item Outil complété (scripts des entretiens utilisateurs, résultats d'une analyse quantitative, etc.)
\item Un document PDF avec les apprentissages clés de cette phase
\item Déposez les documents sur Github, dans un zip nommé « ProjectTitle\_Name\_FirstName », et chaque livrable ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans tous les documents écrits.
\item Soignez l'aspect global des livrables. Ils doivent être clairs, simples et lisibles. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Pistes :}

\begin{itemize}
\item Utilisez autant d'outils que nécessaire, et assurez-vous de faire tout le processus en 4 jours ouvrés !
\end{itemize}

\textbf{Critères :}

\begin{itemize}
\item Persona
\begin{itemize}
\item Le script est la liste des insights que les étudiants utilisent pour créer le persona
\item L'outil complété est un tableau Persona \url{https://miro.medium.com/max/1400/0*RbHfR6BHhhFIENNf}. Assurez-vous que les insights clés viennent du terrain, de la réalité, mais que le persona lui-même est différent d'un seul utilisateur.
\end{itemize}
\end{itemize}

\begin{itemize}
\item Empathy Map
\begin{itemize}
\item Le script est la liste des insights que l'étudiant utilise pour créer l'Empathy Map
\item L'outil complété est une Empathy Map \url{https://miro.medium.com/max/700/1*I1ffOWdPWQva3dCMQE-TAQ.png}.
\end{itemize}
\end{itemize}

\begin{itemize}
\item User Journey
\begin{itemize}
\item Le script est la liste des insights que l'étudiant utilise pour créer le User Journey.
\item L'outil complété est une User Journey Map \url{https://d2slcw3kip6qmk.cloudfront.net/marketing/blog/2017Q3/SEO-initiative-customer-journey-mapping/CustomerJourneyMap1.png}.
\end{itemize}
\end{itemize}

\begin{itemize}
\item Jobs-to-be-done (JTBD)
\begin{itemize}
\item Le JTBD est un outil qui sert de conclusion à un autre des outils précédents. Assurez-vous que :
\begin{itemize}
\item La phrase est complète
\item La partie « Quand » implique une visite sur le site web
\item La partie « Je veux » implique une action pratique
\item La partie « Afin de » implique un objectif psychologique ou émotionnel
\end{itemize}
\end{itemize}
\end{itemize}
