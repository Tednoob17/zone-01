\textbf{Instructions :}

Réalisez un prototype incluant la solution choisie.

\textbf{Livrables :}

\begin{itemize}
\item Photos d'un prototype papier (basse fidélité)
\item Un prototype wireframe animé (moyenne fidélité)
\item Enseignements clés de cette phase
\item Vocabulaire
\begin{itemize}
\item Basse fidélité : prototypes papier - exemple \url{https://miro.medium.com/max/1400/1*5nUfqqA2gjdAYHagjbHA5w.jpeg}
\item Moyenne fidélité : wireframes, noir et blanc, seulement les éléments principaux, sur un outil de prototype - exemple \url{https://miro.medium.com/max/1400/1*eGSfaxwYbxUFomYbyO6GWw.png}
\item Haute fidélité : wireframes avec couleur, styles, détails graphiques et micro-interactions - exemple \url{https://miro.medium.com/max/1400/1*Xn0HSKAvhr4TZzC9lN5udw.gif}
\end{itemize}
\item Déposez les documents sur Github, dans un zip nommé « ProjectTitle\_Name\_FirstName », et chaque livrable ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans tous les documents écrits.
\item Soignez l'aspect global des livrables. Ils doivent être clairs, simples et lisibles. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Pistes :}

\begin{itemize}
\item Utilisez autant d'outils que nécessaire, et assurez-vous de faire tout le processus en 4 jours ouvrés !
\item Vous pouvez utiliser le Card Sorting et les User flows
\end{itemize}

\textbf{Critères :}

\subsubsection*{Critères}

\begin{itemize}
\item User Flow
\end{itemize}

Assurez-vous pour chaque flow :

\begin{itemize}
\item L'utilisateur a un objectif précis
\item Il y a un point de départ et un point d'arrivée  ---  qui est l'objectif de l'utilisateur
\item Il y a une série d'actions organisées en rectangles (actions) ou en losanges (choix)
\item Les actions sont reliées par des flèches
\end{itemize}

\begin{itemize}
\item Tri de cartes
\end{itemize}

Assurez-vous

\begin{itemize}
\item Il y a un script incluant les objectifs de recherche.
\item Les objectifs de recherche doivent être proches de « réorganiser le contenu »
\item Il y a des photos de l'atelier en cours
\item Il y a une nouvelle organisation du contenu montrée dans un tableau avec des post-its (cela peut être une photo ou du numérique)
\end{itemize}
