\textbf{Instructions :}

You are part of a climbing group and volunteer to rebrand the website of your club.

Based on a moodboard, create a design system with at least 20 elements, including atoms, molecules and organisms, and include multistates.

\textbf{Livrables :}

\begin{itemize}
\item A Figma file with a moodboard for a climbing group. Include:
\begin{itemize}
\item Des photos
\item Colors (2 to 3 main colors)
\item Typography
\end{itemize}
\item A Figma file with a library including:
\begin{itemize}
\item At least graphic design 20 elements
\item At least one atom
\item At least one molecule
\item At least one organism
\item At least 5 multistate elements
\end{itemize}
\item Déposez les documents sur Github, dans un zip nommé « ProjectTitle\_Name\_FirstName », et chaque livrable ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans tous les documents écrits.
\item Soignez l'aspect global des livrables. Ils doivent être clairs, simples et lisibles. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Pistes :}

\begin{itemize}
\item Let's be creative! Get inspiration from visuals before diving in.
\item Inspirez-vous des design systems existants. Parcourez Dribbble et la communauté Figma.
\end{itemize}
