\textbf{Contexte :}

Bienvenue dans la 2e quête de UI !

Cette série d'exercices est une excellente occasion de découvrir comment les bibliothèques sont conçues en UI, grâce à Atomic Design.

\textbf{Instructions :}

Parmi ces 4 sites web, faites des captures d'écran de ces éléments :

\begin{itemize}
\item 1 template
\item 1 organisme
\item 1 molécule
\item 1 atome
\end{itemize}

\textbf{Sites :}

\begin{itemize}
\item Alibaba
\item Booking.com
\item Application Easyjet
\item Interrail
\end{itemize}

\textbf{Livrables :}

\begin{itemize}
\item Un fichier Figma de 4 pages
\item Sur chaque page, une capture d'écran d'un template, d'un organisme, d'une molécule et d'un atome
\item Déposez le fichier Figma sur Github, nommé ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans le fichier.
\item Soignez l'aspect global du fichier. Il doit être clair, simple et lisible. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}
