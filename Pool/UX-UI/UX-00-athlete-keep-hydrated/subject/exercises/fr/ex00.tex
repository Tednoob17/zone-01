\textbf{Contexte :}

Bienvenue dans la toute première quête de ce programme.

Votre mission, si vous l'acceptez, est de trouver un moyen d'améliorer l'expérience des athlètes liée à leur hydratation lorsqu'ils courent.

Ce premier projet est très spécial : on vous demande d'aboutir à une solution non numérique. En effet, l'innovation ne rime pas toujours avec numérique. Alors soyons créatifs et sortons des sentiers battus !

\textbf{Recommandations générales :}

\begin{itemize}
\item Sortez des sentiers battus. Soyez curieux. Suivez les tendances design sur YouTube, LinkedIn, dans les podcasts, sur les comptes Instagram. Explorez Internet dès que vous découvrez un nouveau concept. Construisez votre propre culture du design.
\item Documentez tout ce que vous faites, prenez des notes, ouvrez un compte Medium pour identifier et montrer vos livrables, réflexions et retours. Ce sera utile pour votre portfolio !
\item Faites confiance au processus de design. Une étape après l'autre.
\item Le design a besoin d'échouer.
\end{itemize}
L'échec est même une étape nécessaire, mais idéalement il devrait survenir avant le lancement d'un produit, pendant les phases de prototype et de test
\begin{itemize}
\item Créez des liens. Utilisez LinkedIn, vos amis, les amis d'amis pour rencontrer régulièrement des designers et leur demander comment ils pratiquent le design dans leur organisation. Qui sait, un jour ils se souviendront de vous et vous proposeront un contrat !
\item Amusez-vous !!
\end{itemize}

\textbf{Instructions :}

\begin{itemize}
\item Lire tous les scripts très attentivement
\item Extraire au moins 6 insights et les rédiger dans un fichier PDF
\begin{itemize}
\item Les insights doivent être partagés par plusieurs personnes ou cohérents avec ce que d'autres ont déjà vécu
\item Pour chaque insight, indiquer qui l'a formulé.
\end{itemize}
\item Définition d'« insight » : un enseignement clé tiré de ce que vous avez vu, lu ou entendu.
\end{itemize}

\textbf{Livrables :}

\begin{itemize}
\item Créer un document PDF et rédiger au moins 6 insights ainsi que le nom de la ou des personnes qui les ont formulés.
\item Déposez le PDF sur Github, nommé ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans le document.
\item Soignez l'aspect global du document. Il doit être clair, simple et lisible. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Pistes :}

\begin{itemize}
\item Exemples d'insights tirés des scripts (liste non exhaustive) :
\begin{itemize}

\item Ne boit pas trop juste avant la course parce que ça me fait mal au ventre (Nathan, Anaelle)

\begin{itemize}
\item Voici le script d'entretien utilisé pour mener les sept entretiens utilisateurs.
\item Guide d'entretien :
\end{itemize}

Bonjour ! Je m'appelle Agathe et je mène une recherche sur les athlètes et les personnes qui pratiquent un sport régulièrement. Je serais donc très heureuse de vous poser quelques questions sur votre façon de courir, vos habitudes, et les points de douleur que vous pourriez rencontrer.

Cet entretien durera probablement 20 à 30 minutes.

Avez-vous des questions avant de commencer ?

Course à pied

\begin{itemize}
\item Quels sports pratiquez-vous ?
\item À quelle fréquence courez-vous ?
\item Quand êtes-vous sorti courir pour la dernière fois ?
\end{itemize}

Courses

\begin{itemize}
\item Quelle a été la dernière course que vous avez courue ?
\item Comment c'était ? Parlez-moi de l'expérience que vous avez vécue.
\item Comment vous êtes-vous préparé·e ?
\item Qu'auriez-vous fait différemment ? Pourquoi ?
\end{itemize}

Hydratation

\begin{itemize}
\item Que vous souvenez-vous de la façon dont vous vous êtes hydraté ?
\item Comment avez-vous géré votre hydratation ?
\item Vous êtes-vous déjà retrouvé en difficulté à cause de l'hydratation ? Que s'est-il passé ?
\item Que ne referiez-vous jamais ? Pourquoi ?
\end{itemize}

Voilà, nous avons passé toutes les questions que j'avais.

Merci beaucoup pour votre temps !

J'ai une dernière faveur à vous demander : connaissez-vous quelqu'un qui court fréquemment et qui serait disponible pour un entretien ?
