\textbf{Instructions:}

Run a desirability test!

The point of this phase is to make sure the values and the spirit you chose for your design.

\begin{itemize}
\item Get back to the values and spirit you chose in Ex 1. Extract 2 to 5 adjectives.
\item Prepare a board with 25+ adjectives, randomly distributed.
\item Show your design to 5 different people, and ask them to select the adjectives among the list from the board that they are inspired with.
\item If the selected adjectives chosen by the users are consistent with the ones you had chosen, congratulations!
\item If the selected adjectives chosen by the users are not consistent, that's fine! Make 3 suggestions about how to make your moodboard and library evolve.
\end{itemize}

\textbf{Deliverables:}

\begin{itemize}
\item A desirability testing board with 25+ different adjectives
\item Pictures from the desirability test
\item A PDF document with the outcomes of the desirability test
\item If the outcomes are not consistent with the values, 3 suggestions on how to make the moodboard and design library evolve.
\item Upload the documents on Github, in a zip folder named "ProjectTitle\_Name\_FirstName", with all project deliverables as follows: "Name\_FirstName\_DeliverableName\_Date\_VersionNumber".  For example, the first deliverable can be named as "Doe\_John\_MidFiPrototype\_05242024\_V1".
\item Add a title within all written documents.
\item Pay attention to the global aspect of the deliverables. They must be clear, simple and easy to read. You can get inspiration on canva.com but don't overload your design with too much details!
\end{itemize}

\textbf{Tips:}

\begin{itemize}
\item Avoid confirmation biais: don't tell them the values and ask them to approve them!
\item Good to know: Desirability testing is great to assess the impressions a design gives to the users. Whereas Usability testing is great to understand what users understand your prototype and how they navigate across the product.
\end{itemize}
