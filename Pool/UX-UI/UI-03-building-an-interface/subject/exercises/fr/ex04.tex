\textbf{Instructions :}

Réalisez un test de désirabilité !

L'objectif de cette phase est de s'assurer des valeurs et de l'esprit que vous avez choisis pour votre design.

\begin{itemize}
\item Revenez aux valeurs et à l'esprit que vous avez choisis dans l'Ex 1. Extrayez 2 à 5 adjectifs.
\item Préparer un tableau avec plus de 25 adjectifs, distribués aléatoirement.
\item Montrez votre design à 5 personnes différentes, et demandez-leur de sélectionner parmi la liste du tableau les adjectifs qui les inspirent.
\item Si les adjectifs sélectionnés par les utilisateurs sont cohérents avec ceux que vous aviez choisis, félicitations !
\item Si les adjectifs sélectionnés par les utilisateurs ne sont pas cohérents, ce n'est pas grave ! Faites 3 suggestions sur la façon de faire évoluer votre moodboard et votre bibliothèque.
\end{itemize}

\textbf{Livrables :}

\begin{itemize}
\item Un board de test de désirabilité avec plus de 25 adjectifs différents
\item Photos du test de désirabilité
\item Un document PDF avec les résultats du test de désirabilité
\item Si les résultats ne sont pas cohérents avec les valeurs, 3 suggestions pour faire évoluer le moodboard et la bibliothèque de design.
\item Déposez les documents sur Github, dans un zip nommé « ProjectTitle\_Name\_FirstName », et chaque livrable ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans tous les documents écrits.
\item Soignez l'aspect global des livrables. Ils doivent être clairs, simples et lisibles. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Pistes :}

\begin{itemize}
\item Évitez le biais de confirmation : ne leur donnez pas les valeurs pour leur demander de les approuver !
\item Bon à savoir : le test de désirabilité est idéal pour évaluer les impressions qu'un design donne aux utilisateurs. Tandis que le test d'utilisabilité est idéal pour comprendre ce que les utilisateurs comprennent de votre prototype et comment ils naviguent dans le produit.
\end{itemize}
