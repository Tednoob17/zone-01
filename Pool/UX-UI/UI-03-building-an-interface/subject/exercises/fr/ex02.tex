\textbf{Instructions :}

Based on the wireframes and your design system library, take your mid-fidelity prototype to a high-fidelity level!

Select 5 screens that will show the user flow of a customer who:

\begin{itemize}
\item arrives on the homepage
\item browses the content
\item checks one product page
\item adds the product to the cart
\item checks out
\end{itemize}

Use your components, call to actions and visuals to complete the wireframes.

\textbf{Livrables :}

\begin{itemize}
\item 5 high-fidelity screens from Figma
\item Déposez le fichier Figma sur Github, nommé ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans le fichier.
\item Soignez l'aspect global du fichier. Il doit être clair, simple et lisible. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}
