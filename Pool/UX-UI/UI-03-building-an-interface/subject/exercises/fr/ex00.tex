\textbf{Contexte :}

Dans cette quête, vous devrez construire votre propre interface.

Après avoir conçu votre propre style guide avec un moodboard, des couleurs et une typographie, vous pouvez utiliser la série de principes de cohérence, la structure atomic design, les techniques pour construire votre propre library, puis une série d'écrans. Étape par étape, vous aurez construit un prototype haute fidélité animé.

La toute dernière étape sera de le tester auprès d'utilisateurs pour détecter les impressions qu'ils ont en découvrant votre application.

Encore une fois, n'hésitez pas à puiser autant d'inspiration que nécessaire dans les design systems existants. Dribbble, la cohérence et la structure sont vos meilleurs amis !

\textbf{Instructions :}

Votre agence travaille sur un produit numérique pour créer une application e-commerce d'appareils électroniques d'occasion. Vous collaborez avec un UX designer de votre équipe. Ils ont conçu les wireframes et vous les transmettent !

Concevez un style guide (= un moodboard avec typographie + exemples de typographie avec boutons, titre, description et contenu).

Réfléchissez aussi aux valeurs et à l'esprit que vous voulez diffuser à travers ce moodboard, nous y reviendrons à l'Ex. 5.

\textbf{Livrables :}

\begin{itemize}
\item Une planche d'ambiance Figma qui comprend :
\begin{itemize}
\item Des photos
\item 2 à 3 couleurs principales
\item Exemples de typographie appliquée à des éléments graphiques
\begin{itemize}
\item Titre
\item Description ou sous-titre
\item Contenu
\item Bouton
\end{itemize}
\end{itemize}
\item Déposez le fichier Figma sur Github, nommé ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans le fichier.
\item Soignez l'aspect global du fichier. Il doit être clair, simple et lisible. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}
