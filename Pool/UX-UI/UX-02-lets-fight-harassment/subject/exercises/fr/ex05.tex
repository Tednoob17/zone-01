\textbf{Instructions :}

Maintenant que vous avez votre persona, il est temps de le mettre en mouvement.

Concevez un User Journey pour représenter votre persona dans son environnement au fil du temps, avec les étapes ou actions clés liées à notre sujet actuel (le harcèlement).

La timeline peut être d'une journée, de quelques heures, ou d'une semaine. Incluez les moments clés liés au harcèlement ainsi que les émotions liées à chaque étape. Utilisez le matériel de vos entretiens et enquêtes.

Ensuite, mettez en évidence les principaux points de douleur à résoudre.

\textbf{Livrable :}

\begin{itemize}
\item Un document Figma avec le parcours utilisateur de votre persona
\item Déposez le fichier Figma sur Github, nommé ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans le fichier.
\item Soignez l'aspect global du fichier. Il doit être clair, simple et lisible. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}
