\textbf{Instructions :}

\begin{itemize}
\item Créer un guide d'entretien
\item Mener 3 entretiens avec des adolescents
\end{itemize}

Après en avoir appris davantage sur les tendances et le « quoi » que les gens font grâce aux questionnaires, l'objectif principal est de comprendre le « pourquoi ».

\textbf{Livrables :}

\begin{itemize}
\item Un document PDF avec un guide d'entretien
\item Un document PDF avec 3 scripts
\item Un diagramme d'affinité à partir de vos entretiens (PDF ou numérique, sur Miro ou Figma par exemple)
\item Déposez les documents sur Github, dans un zip nommé « ProjectTitle\_Name\_FirstName », et chaque livrable ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans tous les documents écrits.
\item Soignez l'aspect global des livrables. Ils doivent être clairs, simples et lisibles. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Pistes :}

Voici les étapes recommandées :

1. Définissez votre objectif, ce que vous cherchez en interviewant des personnes. Habituellement, cela concerne les habitudes de votre utilisateur, et les problèmes les plus douloureux qu'il rencontre sur ce sujet.
2. Notez 1 à 3 hypothèses que vous avez sur ce sujet, qui doivent être soit confirmées soit infirmées.
3. Choisissez 3 à 5 sujets sur lesquels il vous faut de l'information.
4. Pour chaque sujet, rédigez 1 à 3 questions ouvertes. Rappelez-vous, votre utilisateur ne peut pas répondre par « Oui » ou « Non » ! Ex. : Comment, Pourquoi, Quoi, Quand, Parlez-moi de la dernière fois que vous avez... etc. Si vous devez vraiment introduire un nouveau sujet par une question fermée, demandez pourquoi juste après.
5. Rédigez quelques questions de screening pour obtenir quelques données démographiques (âge, métier, localisation, etc.)
6. Structurez vos questions en entonnoir : commencez par des questions larges pour vous concentrer sur des sujets ou situations spécifiques. N'oubliez pas de rester neutre dans votre ton pour laisser l'utilisateur raconter sa propre histoire. Essayez de vous concentrer sur 10 questions principales.
7. Rédigez une introduction de salutation, décrivant brièvement (1) qui vous êtes et (2) ce que vous cherchez. Pas besoin d'en dire trop, mais assez pour fournir un cadre et l'objectif de l'entretien.
8. Rédigez une conclusion pour remercier votre utilisateur pour son temps, et préparez les prochaines étapes. Ex. : demander à être mis en contact avec quelqu'un qu'il connaît et qui pourrait être intéressé par ce sujet, etc.
