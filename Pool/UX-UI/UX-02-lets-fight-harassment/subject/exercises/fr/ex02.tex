\textbf{Instructions :}

Définissez et déployez votre stratégie de diffusion auprès des adolescents (15-18 ans)

Même si une enquête digne de ce nom nécessite au moins 100 réponses, pour cet exercice nous vous demandons d'en obtenir 40.

\textbf{Livrables :}

\begin{itemize}
\item Un document PDF rassemblant votre stratégie. Merci d'inclure :
\begin{itemize}
\item Qui vous ciblez (rappelez-vous, vous pouvez vous concentrer sur votre ville natale aussi bien que sur la planète entière)
\item Quelques idées sur comment les atteindre
\item Les canaux que vous comptez utiliser  ---  soyez précis et incluez les liens vers les groupes, forums, pages, comptes que vous prévoyez d'atteindre
\item Au moins 2 messages différents
\item Un plan A, un plan B, un plan C
\end{itemize}
\item Un document pour exprimer vos principaux retours après avoir mené votre stratégie de diffusion : qu'est-ce qui a le mieux fonctionné ? avez-vous rencontré des difficultés ? Lesquelles ? Comment les avez-vous surmontées ?
\item Déposez les documents sur Github, dans un zip nommé « ProjectTitle\_Name\_FirstName », et chaque livrable ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans tous les documents écrits.
\item Soignez l'aspect global des livrables. Ils doivent être clairs, simples et lisibles. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Pistes :}

Pour cela, vous devez être créatif et stratégique !

\begin{itemize}
\item Qui ciblez-vous ? Adolescents, harceleurs, persécuteurs, témoins, parents, enseignants, personnes de l'administration ? D'où ?
\item Comment les atteindre ? Par quels canaux ? Sur quels forums, groupes, avec quels hashtags ? Tenterez-vous de les atteindre via des influenceurs ?
\item Quels mots et quel ton allez-vous utiliser ?
\item Comment allez-vous les aborder ? Quel message allez-vous écrire ?
\item Qu'avez-vous prévu s'ils ne répondent pas tout de suite ?
\end{itemize}

Une fois votre stratégie préparée, déployez-la !
