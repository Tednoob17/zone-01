\textbf{Instructions :}
À partir de votre travail précédent, de votre persona et du principal pain point de votre user journey, définissez un problem statement qui clarifierait le problème principal que vous voulez traiter.
Vous pouvez utiliser l'exercice How Might We en binôme.

Ensuite, définissez 3 KPI (Key Performance Indicators) qui vous aideront à mesurer la définition de Done et le succès de la solution.

\textbf{Livrables :}

\begin{itemize}
\item Un document PDF avec un énoncé de problème et 3 KPIs pour mesurer l'impact de la solution
\item Déposez le PDF sur Github, nommé ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans le document.
\item Soignez l'aspect global du document. Il doit être clair, simple et lisible. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}
