\textbf{Instructions :}

Créons un persona basé sur votre recherche quantitative et vos entretiens.

Votre fiche persona doit inclure les tendances communes parmi les personnes auprès desquelles vous avez obtenu des données (habitudes, verbatims, peurs, motivations, frustrations et points de douleur).

Rappel : Votre persona est fictif et ne doit pas avoir le nom exact ni la photo de quelqu'un que vous avez interviewé, mais souvenez-vous qu'un persona est là pour vous permettre de prendre des décisions en tant que designer.

\textbf{Livrables :}

\begin{itemize}
\item Une fiche persona PDF extraite d'un fichier Figma
\item Déposez le PDF sur Github, nommé ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans le document.
\item Soignez l'aspect global du document. Il doit être clair, simple et lisible. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}
