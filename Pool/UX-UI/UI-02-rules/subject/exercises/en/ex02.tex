\textbf{Instructions:}

Choose a website you find particularly accessible. Find at least 3 concrete examples of accessible measures and explain how they ease the reading or perception of visual content.

\textbf{Deliverables:}

\begin{itemize}
\item A 3-page Figma file with 3 different elements from a website (it can be from 3 different websites) that are accessible. The three measures must be different.
\item Upload the Figma file on Github, labeled as follows: "Name\_FirstName\_DeliverableName\_Date\_VersionNumber". For example, it can be labeled as "Doe\_John\_MidFiPrototype\_05242024\_V1".
\item Add a title within the file.
\item Pay attention to the global aspect of the file. It must be clear, simple and easy to read. You can get inspiration on canva.com but don't overload your design with too much details!
\end{itemize}

\textbf{Criteria:}

\begin{itemize}
\item Examples of measures
\begin{itemize}
\item Color contrast
\item Highlighted or enlarged text when hovering
\item Links color that is different from the body text's
\item Breadcrumbs to indicate where you are in terms of navigation
\item In forms, the title of the case should be above the text zone
\item Error states
\item etc.
\end{itemize}
