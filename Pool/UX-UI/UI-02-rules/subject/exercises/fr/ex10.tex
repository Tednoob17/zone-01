\textbf{Instructions :}

Choisissez un site web ou une application de votre choix*. Surlignez 5 signes de cohérence à travers les pages.

*Airbnb, Google, Apple, Amazon, Facebook, Instagram et WhatsApp ne sont pas acceptés.

\textbf{Livrable :}

\begin{itemize}
\item Un fichier Figma rassemblant au moins 5 signes de cohérence.
\item Déposez le fichier Figma sur Github, nommé ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans le fichier.
\item Soignez l'aspect global du fichier. Il doit être clair, simple et lisible. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Ressources :}

\begin{itemize}
\item 7 conseils pour concevoir la cohérence \url{https://designshack.net/articles/graphics/7-tips-for-designing-consistency/}
\item La valeur d'un design cohérent \url{https://www.invisionapp.com/inside-design/consistent-design/}
\item Cohérence et standards - Exemples des heuristiques de design de Nielsen \url{https://medium.com/@gregoralbrecht/consistency-and-standards-nielsens-design-heuristic-explained-ac91f450fd8}
\item L'importance de la cohérence dans le travail de design \url{https://yesimadesigner.com/the-importance-of-consistancy-in-design-work/}
\item Exemples de signes de cohérence :
\begin{itemize}
\item couleurs
\item boutons de même forme
\item alignement
\item pages produit cohérentes (avec des frameworks identiques)
\item etc.
\end{itemize}
\end{itemize}
