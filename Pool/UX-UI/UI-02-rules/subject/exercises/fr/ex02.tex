\textbf{Instructions :}

Choisissez un site web que vous trouvez particulièrement accessible. Trouvez au moins 3 exemples concrets de mesures d'accessibilité et expliquez comment elles facilitent la lecture ou la perception du contenu visuel.

\textbf{Livrables :}

\begin{itemize}
\item Un fichier Figma de 3 pages avec 3 éléments différents issus d'un site (ils peuvent venir de 3 sites différents) qui sont accessibles. Les trois mesures doivent être différentes.
\item Déposez le fichier Figma sur Github, nommé ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans le fichier.
\item Soignez l'aspect global du fichier. Il doit être clair, simple et lisible. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Critères :}

\begin{itemize}
\item Exemples de mesures
\begin{itemize}
\item Contraste des couleurs
\item Texte mis en évidence ou agrandi au survol
\item Couleur des liens différente de celle du corps de texte
\item Un fil d'Ariane pour indiquer où vous êtes dans la navigation
\item Dans les formulaires, le titre du champ doit être au-dessus de la zone de texte
\item États d'erreur
\item etc.
\end{itemize}
