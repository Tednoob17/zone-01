\textbf{Instructions :}

Parcourez Internet et trouvez au moins 5 exemples différents de micro-interactions ou micro-animations de feedback sur des sites web ou des applications.

Attention ! Le feedback est utile pour fournir de l'information à l'utilisateur, pas seulement pour montrer un design accrocheur. Vous devez faire la différence.

\textbf{Livrable :}

\begin{itemize}
\item Un fichier Figma rassemblant 5 exemples de micro-interactions ou d'animations de \textbf{feedback}. Dans chaque exemple, montrez les différentes versions de l'élément.
\item Déposez le fichier Figma sur Github, nommé ainsi : « Name\_FirstName\_DeliverableName\_Date\_VersionNumber ». Exemple : « Doe\_John\_MidFiPrototype\_05242024\_V1 ».
\item Ajoutez un titre dans le fichier.
\item Soignez l'aspect global du fichier. Il doit être clair, simple et lisible. Vous pouvez regarder canva.com, sans surcharger le dessin de détails.
\end{itemize}

\textbf{Ressources :}

\begin{itemize}
\item Pourquoi utiliser des micro-interactions dans votre design \url{https://hike.one/update/why-use-micro-animations-in-your-design}
\item Micro-interactions : pourquoi, quand et comment les utiliser pour booster l'UX \url{https://uxdesign.cc/micro-interactions-why-when-and-how-to-use-them-to-boost-the-ux-17094b3baaa0}
\end{itemize}

\textbf{Pistes :}

\begin{itemize}
\item Le feedback, c'est lorsque l'application envoie spécifiquement une information à l'utilisateur, comme :
\item Paiement accepté
\item Fil actualisé
\item Informations enregistrées
\item etc.
\end{itemize}
